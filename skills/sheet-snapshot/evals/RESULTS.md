## ข้อสังเกต

1. **จุดที่ skill ต่างจาก baseline ชัดที่สุด คือขั้นตอน publish:** baseline ไม่ถามเลยสักครั้งใน 3 โจทย์ (ถ้าผู้ใช้ขอลิงก์ จะ publish ทันที) ส่วนมี skill ถามครบ 3 ตัวเลือกทุกครั้ง และเตือนเมื่อในไฟล์มีข้อมูลส่วนตัว
2. **baseline สร้างหน้า HTML ที่ upload มาเทียบได้เองแล้วใน 2 โจทย์:** เป็นจุดที่ต่างจาก iteration-2 ซึ่ง baseline ไม่เคยทำได้ แต่ผลยังไม่นิ่ง เพราะโจทย์ 1 ยังได้แค่ JSON กับ CLI
3. **ส่วนที่ skill ช่วยได้จริงคือความสม่ำเสมอและความเร็ว:** มี skill ได้หน้าตาเดียวกันทุกครั้ง และเร็วกว่าเฉลี่ย 45 วินาที ในโจทย์ 2 baseline ใช้ 163 วินาทีเพราะเขียน template ขึ้นใหม่เองทั้งหมด
4. **เกณฑ์ที่ไม่ได้แยกว่า skill ดีกว่า:** อ่านข้อมูลครบ, วันที่ ISO และเลือก key ถูก ผ่านทั้งสองแบบ
5. **จุดอ่อนที่ยังเหลือ:** `--key` ใช้กับทุก sheet พร้อมกัน ในโจทย์ 1 จึงต้องปล่อยให้หน้าเว็บเลือก `Supplier Code` เอง ไฟล์จริงที่มีหลาย sheet (เช่น Service Inventory ที่มี 25 sheet) จะเห็นปัญหานี้ชัดขึ้น ควรรองรับ key แยกราย sheet
